 # 1.1 - Καλωσόρισμα

## Στόχος

Να γνωρίσουμε τη δομή της σειράς, τον τρόπο που θα εργαστούμε και το τελικό αποτέλεσμα που θα δημιουργήσουμε.

---

# Τι θα μάθουμε

Στο τέλος αυτής της σειράς θα μπορείτε να δημιουργείτε ολοκληρωμένες δυναμικές web εφαρμογές από την αρχή, χωρίς να βασίζεστε σε έτοιμα CMS ή Frameworks.

Θα μάθετε:

- HTML
- CSS
- Bootstrap
- PHP
- MySQL
- Git & GitHub
- Ασφάλεια εφαρμογών
- Δημοσίευση (Deployment)

Πέρα όμως από τις τεχνολογίες, θα μάθετε να σκέφτεστε σαν προγραμματιστές και να μπορείτε να αναλύετε οποιοδήποτε project.

---

# Σε ποιους απευθύνεται

Η σειρά απευθύνεται:

- Σε αρχάριους χωρίς καμία γνώση.
- Σε όσους γνωρίζουν λίγο HTML ή PHP αλλά έχουν κενά.
- Σε φοιτητές.
- Σε επαγγελματίες που θέλουν να δημιουργούν τις δικές τους εφαρμογές.

Δεν απαιτείται καμία προηγούμενη εμπειρία στον προγραμματισμό. Αρκεί να γνωρίζετε τη βασική χρήση υπολογιστή και την εγκατάσταση απλών εφαρμογών.

---

# Τι θα δημιουργήσουμε

Δεν θα γράψουμε απλώς μικρά παραδείγματα.

Σε όλη τη διάρκεια της σειράς θα αναπτύσσουμε σταδιακά μία πραγματική web εφαρμογή.

Σε κάθε ενότητα θα προσθέτουμε νέες δυνατότητες, μέχρι να ολοκληρωθεί ένα πλήρες project.

Έτσι κάθε νέα γνώση θα εφαρμόζεται αμέσως στην πράξη.

---

# Πώς είναι οργανωμένη η σειρά

Κάθε μάθημα ακολουθεί την ίδια δομή:

1. Θεωρία
2. Παράδειγμα
3. Εφαρμογή στο βασικό project
4. Άσκηση
5. Λύση της προηγούμενης άσκησης

Με αυτόν τον τρόπο η γνώση χτίζεται σταδιακά και κάθε μάθημα βασίζεται στα προηγούμενα.

---

# Τι θα χρειαστείτε

Για να παρακολουθήσετε τη σειρά θα χρειαστείτε:

- Έναν υπολογιστή.
- Βασική γνώση χρήσης υπολογιστή και εγκατάστασης εφαρμογών.
- Όρεξη για μάθηση.
- Λίγο χρόνο για εξάσκηση.

Τα περισσότερα εργαλεία που θα χρησιμοποιήσουμε είναι δωρεάν.

Κατά τη διάρκεια της σειράς θα δείξουμε πώς μπορείτε να αναπτύσσετε τις εφαρμογές σας τοπικά χρησιμοποιώντας το XAMPP. Ωστόσο, θα σας προτείνω να επενδύσετε ένα μικρό ποσό σε ένα οικονομικό πακέτο φιλοξενίας (Hosting).

Η ανάπτυξη σε πραγματικό server προσφέρει σημαντικά πλεονεκτήματα:

- Εργάζεστε σε πραγματικό περιβάλλον λειτουργίας.
- Μαθαίνετε από την πρώτη στιγμή πώς δημοσιεύονται πραγματικές εφαρμογές.
- Αποφεύγετε προβλήματα που οφείλονται αποκλειστικά στο τοπικό περιβάλλον ανάπτυξης.
- Όταν κάτι δεν λειτουργεί σωστά, γνωρίζετε ότι το πρόβλημα βρίσκεται σχεδόν πάντα στον κώδικά σας και όχι στις ιδιαιτερότητες ενός τοπικού περιβάλλοντος ανάπτυξης.

Αν δεν θέλετε να επενδύσετε σε Hosting από την αρχή, μπορείτε να παρακολουθήσετε και να ολοκληρώσετε ολόκληρη τη σειρά χρησιμοποιώντας μόνο το δωρεάν XAMPP.

---

# Συμβουλές

- Μην παραλείπετε μαθήματα.
- Γράφετε πάντα μόνοι σας τον κώδικα.
- Κάντε τις ασκήσεις.
- Αν κάτι δεν γίνει κατανοητό, συνεχίστε και επιστρέψτε αργότερα.

Πολλές έννοιες θα γίνουν ξεκάθαρες όταν χρησιμοποιηθούν στην πράξη.

---

# Στο επόμενο μάθημα

Στο επόμενο μάθημα θα γνωρίσουμε τη βασική ορολογία του Web Development, ώστε να μιλάμε όλοι την ίδια "γλώσσα" πριν ξεκινήσουμε τον προγραμματισμό.
