# 1.2 - Πώς θα χρησιμοποιούμε την Τεχνητή Νοημοσύνη

## Στόχος

Να μάθουμε πώς η Τεχνητή Νοημοσύνη μπορεί να γίνει ένα από τα σημαντικότερα εργαλεία εκμάθησης προγραμματισμού, χωρίς όμως να αντικαταστήσει τη δική μας σκέψη.

---

# Η Τεχνητή Νοημοσύνη άλλαξε τα πάντα

Μέχρι πριν λίγα χρόνια, όταν ένας προγραμματιστής αντιμετώπιζε ένα πρόβλημα, έπρεπε να:

- αναζητήσει στο Google,
- διαβάσει δεκάδες άρθρα,
- ψάξει σε forums,
- δοκιμάσει πολλές διαφορετικές λύσεις.

Σήμερα έχουμε στη διάθεσή μας ένα εργαλείο που μπορεί να μας εξηγήσει σχεδόν οποιαδήποτε έννοια μέσα σε λίγα δευτερόλεπτα.

Αυτό όμως δεν σημαίνει ότι πρέπει να αφήσουμε την ΑΙ να κάνει τη δουλειά μας.

---

# Η φιλοσοφία αυτής της σειράς

Σε αυτή τη σειρά δεν θα χρησιμοποιούμε την Τεχνητή Νοημοσύνη για να γράφει ολόκληρες εφαρμογές για εμάς.

Θα τη χρησιμοποιούμε ως:

- δάσκαλο,
- σύμβουλο,
- βοηθό,
- συνεργάτη,
- συνομιλητή.

Στόχος μας είναι να μάθουμε να γράφουμε μόνοι μας κώδικα και να καταλαβαίνουμε κάθε γραμμή που δημιουργούμε.

---

# Πώς θα χρησιμοποιούμε την ΑΙ

Η ΑΙ είναι εξαιρετική όταν θέλουμε:

- να μας εξηγήσει μια έννοια,
- να μας δείξει ένα παράδειγμα,
- να μας βοηθήσει να εντοπίσουμε ένα λάθος,
- να μας προτείνει διαφορετικές προσεγγίσεις,
- να μας εξηγήσει γιατί ένας κώδικας δεν λειτουργεί,
- να μας προτείνει τρόπους βελτίωσης.

Με λίγα λόγια, θα τη χρησιμοποιούμε για να μαθαίνουμε γρηγορότερα.

---

# Πώς ΔΕΝ θα χρησιμοποιούμε την ΑΙ

Δεν θα αντιγράφουμε κώδικα που δεν καταλαβαίνουμε.

Δεν θα ζητάμε:

> "Γράψε μου μια εφαρμογή."

Θα ζητάμε:

> "Εξήγησέ μου γιατί ο δικός μου κώδικας δεν λειτουργεί."

ή

> "Υπάρχει καλύτερος τρόπος να λύσω αυτό το πρόβλημα;"

---

# Η μεγαλύτερη παγίδα

Η Τεχνητή Νοημοσύνη μπορεί να γράψει χιλιάδες γραμμές κώδικα μέσα σε λίγα δευτερόλεπτα.

Αν όμως δεν μπορείτε να καταλάβετε αυτόν τον κώδικα, δεν θα μπορείτε:

- να διορθώσετε τα λάθη,
- να τον επεκτείνετε,
- να τον συντηρήσετε,
- να δημιουργήσετε κάτι διαφορετικό.

Τότε δεν θα είστε εσείς ο προγραμματιστής.

Θα είστε απλώς ο άνθρωπος που κάνει αντιγραφή και επικόλληση.

---

# Οι τέσσερις κανόνες μας

1. Η ΑΙ δεν αντικαθιστά τη σκέψη.
2. Δεν αντιγράφουμε κώδικα που δεν καταλαβαίνουμε.
3. Ζητάμε εξηγήσεις και όχι μόνο λύσεις.
4. Δοκιμάζουμε και επαληθεύουμε πάντα όσα μας προτείνει.

---

# Η υπόσχεσή μου

Σε όλη αυτή τη σειρά θα χρησιμοποιώ και εγώ την Τεχνητή Νοημοσύνη.

Κάθε φορά όμως θα σας δείχνω γιατί τη χρησιμοποιώ, τι της ζητάω και πώς αξιολογώ τις απαντήσεις της.

Στόχος μου δεν είναι να μάθετε να χρησιμοποιείτε ένα συγκεκριμένο εργαλείο.

Στόχος μου είναι να μάθετε να συνεργάζεστε σωστά με οποιοδήποτε εργαλείο Τεχνητής Νοημοσύνης εμφανιστεί στο μέλλον.

---
