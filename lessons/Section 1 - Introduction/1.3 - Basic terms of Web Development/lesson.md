# 1.3 - Βασικοί Όροι Web Development

## Στόχος

Να γνωρίσουμε τους βασικότερους όρους που θα χρησιμοποιούμε σε όλη τη διάρκεια της σειράς, ώστε από εδώ και πέρα να μιλάμε την ίδια "γλώσσα".

---

# Τι είναι το Web Development

Web Development ονομάζεται η διαδικασία δημιουργίας ιστοσελίδων και web εφαρμογών.

Από μια απλή προσωπική ιστοσελίδα μέχρι μια πολύπλοκη εφαρμογή όπως το Facebook ή το e-shop μιας μεγάλης εταιρείας, όλα αποτελούν προϊόντα του Web Development.

---

# HTML

Η HTML (HyperText Markup Language) αποτελεί τη δομή μιας ιστοσελίδας.

Με αυτήν δημιουργούμε:

- επικεφαλίδες
- παραγράφους
- εικόνες
- συνδέσμους
- πίνακες
- φόρμες

Η HTML περιγράφει **τι υπάρχει** μέσα σε μια σελίδα.

---

# CSS

Η CSS (Cascading Style Sheets) καθορίζει την εμφάνιση της ιστοσελίδας.

Με αυτήν ορίζουμε:

- χρώματα
- γραμματοσειρές
- αποστάσεις
- διαστάσεις
- στοίχιση
- responsive εμφάνιση

Η CSS περιγράφει **πώς φαίνεται** μια σελίδα.

---

# JavaScript

Η JavaScript προσθέτει αλληλεπίδραση.

Χρησιμοποιείται για:

- animations
- έλεγχο φορμών
- δυναμική αλλαγή περιεχομένου
- επικοινωνία με τον server
- δημιουργία σύνθετων εφαρμογών

Η JavaScript περιγράφει **πώς συμπεριφέρεται** μια σελίδα.

---

# PHP

Η PHP είναι γλώσσα προγραμματισμού που εκτελείται στον server.

Με αυτήν μπορούμε:

- να διαχειριζόμαστε χρήστες
- να αποθηκεύουμε δεδομένα
- να δημιουργούμε δυναμικές σελίδες
- να επικοινωνούμε με βάσεις δεδομένων

---

# MySQL

Η MySQL είναι ένα Σύστημα Διαχείρισης Βάσεων Δεδομένων.

Σε αυτή αποθηκεύονται πληροφορίες όπως:

- χρήστες
- προϊόντα
- παραγγελίες
- άρθρα
- μηνύματα

---

# Frontend Development

Frontend είναι ό,τι βλέπει και χρησιμοποιεί ο επισκέπτης.

Περιλαμβάνει κυρίως:

- HTML
- CSS
- JavaScript

---

# Backend Development

Backend είναι ό,τι εκτελείται στον server.

Περιλαμβάνει:

- PHP
- Βάσεις δεδομένων
- Authentication
- Business Logic
- APIs

Ο χρήστης δεν βλέπει ποτέ τον Backend κώδικα.

---

# Full Stack Developer

Ένας Full Stack Developer ασχολείται τόσο με το Frontend όσο και με το Backend μιας εφαρμογής.

Γνωρίζει πώς λειτουργεί ολόκληρο το σύστημα από την αρχή μέχρι το τέλος.

---

# Framework

Ένα Framework είναι ένα έτοιμο σύνολο εργαλείων και βιβλιοθηκών που βοηθά στην ανάπτυξη εφαρμογών.

Δεν είναι γλώσσα προγραμματισμού.

Αποτελεί ένα οργανωμένο περιβάλλον που κάνει την ανάπτυξη γρηγορότερη και πιο τυποποιημένη.

Στο επόμενο μάθημα θα γνωρίσουμε τα σημαντικότερα Frameworks.

---

# Responsive Design

Responsive Design σημαίνει ότι μια ιστοσελίδα προσαρμόζεται αυτόματα σε διαφορετικές συσκευές, όπως:

- κινητά
- tablets
- laptops
- desktop υπολογιστές

Στόχος είναι να προσφέρει σωστή εμπειρία χρήσης ανεξάρτητα από το μέγεθος της οθόνης.

---

# Ανακεφαλαίωση

Στο μάθημα αυτό γνωρίσαμε:

- τι είναι το Web Development,
- τι είναι η HTML,
- τι είναι η CSS,
- τι είναι η JavaScript,
- τι είναι η PHP,
- τι είναι η MySQL,
- τη διαφορά μεταξύ Frontend και Backend,
- τι σημαίνει Full Stack Developer,
- τι είναι ένα Framework,
- τι σημαίνει Responsive Design.

Δεν χρειάζεται να τα απομνημονεύσετε.

Αρκεί να γνωρίζετε σε γενικές γραμμές τι σημαίνει ο κάθε όρος.  
Στα επόμενα μαθήματα θα τους χρησιμοποιούμε συνεχώς και πολύ σύντομα θα σας γίνουν απολύτως φυσικοί.

---

Στο επόμενο μάθημα θα γνωρίσουμε τα πιο δημοφιλή Frameworks που χρησιμοποιούνται σήμερα στην ανάπτυξη web εφαρμογών και θα καταλάβουμε γιατί υπάρχουν.
