# 1.4 - Δημοφιλή Frameworks

## Στόχος

Να γνωρίσουμε τα σημαντικότερα Frameworks που χρησιμοποιούνται σήμερα στο Web Development και να καταλάβουμε γιατί δημιουργήθηκαν.

---

# Τι είναι ένα Framework

Ένα Framework είναι ένα σύνολο εργαλείων, βιβλιοθηκών και κανόνων που βοηθούν έναν προγραμματιστή να δημιουργεί εφαρμογές γρηγορότερα.

Δεν αποτελεί γλώσσα προγραμματισμού.

Αντίθετα, βασίζεται σε μία υπάρχουσα γλώσσα και προσφέρει έτοιμες λύσεις για συνηθισμένα προβλήματα.

---

# Γιατί δημιουργήθηκαν τα Frameworks

Καθώς οι web εφαρμογές γίνονταν ολοένα και πιο σύνθετες, οι προγραμματιστές διαπίστωσαν ότι έγραφαν ξανά και ξανά τον ίδιο κώδικα.

Για παράδειγμα:

- σύνδεση με βάση δεδομένων,
- σύνδεση και διαχείριση χρηστών,
- αποστολή email,
- δρομολόγηση σελίδων (Routing),
- έλεγχο δικαιωμάτων πρόσβασης,
- μηχανισμούς ασφάλειας.

Αυτό είχε ως αποτέλεσμα να χάνεται πολύτιμος χρόνος για την υλοποίηση λειτουργιών που υπάρχουν σχεδόν σε κάθε εφαρμογή.

Τα Frameworks δημιουργήθηκαν για να προσφέρουν έτοιμες, αξιόπιστες και δοκιμασμένες λύσεις σε αυτά τα συνηθισμένα προβλήματα, επιτρέποντας στους προγραμματιστές να επικεντρωθούν στις πραγματικές ανάγκες της εφαρμογής τους.

Όμως τα Frameworks προσφέρουν κάτι ακόμη πιο σημαντικό.

Επιβάλλουν έναν κοινό τρόπο οργάνωσης του έργου και συγκεκριμένους κανόνες ανάπτυξης.  
Έτσι, όλοι οι προγραμματιστές μιας ομάδας ακολουθούν την ίδια αρχιτεκτονική και τον ίδιο τρόπο γραφής κώδικα.

Φανταστείτε μια εταιρεία με δέκα προγραμματιστές.

Αν ο καθένας οργανώνει το έργο του διαφορετικά, ένας νέος προγραμματιστής θα χρειαστεί αρκετό χρόνο μόνο και μόνο για να καταλάβει πώς είναι δομημένη η εφαρμογή.

Αντίθετα, όταν χρησιμοποιείται ένα Framework, η δομή του έργου είναι προβλέψιμη και κοινή για όλους.  
Έτσι, ένας νέος προγραμματιστής μπορεί να κατανοήσει πολύ πιο γρήγορα τον κώδικα και να συνεχίσει την ανάπτυξη της εφαρμογής χωρίς να χρειάζεται πρώτα να ανακαλύψει τη λογική του προηγούμενου δημιουργού.

---

# Frameworks για PHP

## Laravel

Το Laravel είναι σήμερα το δημοφιλέστερο Framework της PHP.

Χρησιμοποιείται για την ανάπτυξη σύγχρονων web εφαρμογών κάθε μεγέθους.

---

## Symfony

Το Symfony αποτελεί ένα από τα παλαιότερα και πιο αξιόπιστα PHP Frameworks.

Χρησιμοποιείται κυρίως σε μεγάλα και σύνθετα έργα.

---

# Frameworks για Python

## Django

Το Django είναι το πιο γνωστό Framework της Python για ανάπτυξη web εφαρμογών.

Δίνει ιδιαίτερη έμφαση στην ασφάλεια και στην ταχύτητα ανάπτυξης.

---

# Frameworks για Ruby

## Ruby on Rails

Το Ruby on Rails έκανε ιδιαίτερα δημοφιλή την έννοια των σύγχρονων Frameworks.

Είναι γνωστό για την ταχύτητα ανάπτυξης εφαρμογών.

---

# Frameworks και Βιβλιοθήκες JavaScript

## React

Το React χρησιμοποιείται για τη δημιουργία σύγχρονων και διαδραστικών διεπαφών χρήστη (User Interfaces).

Αναπτύχθηκε από τη Meta (Facebook).

---

## Vue

Το Vue είναι ένα ελαφρύ και ιδιαίτερα φιλικό Framework (ή βιβλιοθήκη, ανάλογα με τη χρήση) για ανάπτυξη Frontend εφαρμογών.

---

## Angular

Το Angular αναπτύσσεται από την Google και χρησιμοποιείται κυρίως σε μεγάλες επιχειρησιακές εφαρμογές.

---

## Express.js

Το Express.js χρησιμοποιείται για ανάπτυξη Backend εφαρμογών με τη Node.js και τη JavaScript.

---

# Framework για .NET

## ASP.NET

Το ASP.NET είναι το Framework της Microsoft για ανάπτυξη web εφαρμογών χρησιμοποιώντας την πλατφόρμα .NET.

Χρησιμοποιείται ευρέως σε επιχειρησιακά πληροφοριακά συστήματα.

---

# Ποιο είναι το καλύτερο Framework;

Δεν υπάρχει αντικειμενικά καλύτερο Framework.

Η επιλογή εξαρτάται από:

- το είδος της εφαρμογής,
- την ομάδα ανάπτυξης,
- τις απαιτήσεις του έργου,
- την εμπειρία του προγραμματιστή.

Όλα τα σύγχρονα Frameworks μπορούν να χρησιμοποιηθούν για τη δημιουργία εξαιρετικών εφαρμογών.

---

# Ανακεφαλαίωση

Σε αυτό το μάθημα γνωρίσαμε:

- τι είναι ένα Framework,
- γιατί δημιουργήθηκαν,
- τα σημαντικότερα Frameworks που χρησιμοποιούνται σήμερα,
- σε ποιες γλώσσες βασίζονται.

**Αφού υπάρχουν τόσο ισχυρά Frameworks, γιατί θα ξεκινήσουμε μαθαίνοντας PHP χωρίς κάποιο Framework;**
