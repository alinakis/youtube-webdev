# 1.5 - Γιατί θα μάθουμε πρώτα PHP και μετά Frameworks

## Στόχος

Να κατανοήσουμε γιατί θα ξεκινήσουμε μαθαίνοντας την ίδια τη γλώσσα PHP πριν χρησιμοποιήσουμε κάποιο Framework.

---

# Framework ή PHP;

Μία από τις πιο συνηθισμένες ερωτήσεις που κάνουν οι αρχάριοι είναι:

> "Αφού υπάρχουν Frameworks όπως το Laravel, γιατί να μάθω πρώτα PHP;"

Η απάντηση είναι απλή.

Ένα Framework δεν αντικαθιστά τη γλώσσα προγραμματισμού.

Βασίζεται σε αυτήν.

Για να χρησιμοποιήσετε σωστά ένα Framework, πρέπει πρώτα να γνωρίζετε τη γλώσσα πάνω στην οποία έχει δημιουργηθεί.

---

# Τα Frameworks είναι εργαλεία

Ένα Framework είναι ένα εργαλείο που βοηθά έναν προγραμματιστή να αναπτύσσει εφαρμογές πιο γρήγορα.

Δεν αντικαθιστά όμως τις γνώσεις προγραμματισμού.

Είναι όπως ένα ηλεκτρικό τρυπάνι.

Το τρυπάνι κάνει τη δουλειά πιο γρήγορα, αλλά πρέπει πρώτα να ξέρετε πού και γιατί θα ανοίξετε την τρύπα.

---

# Η γνώση της PHP είναι η βάση

Μαθαίνοντας πρώτα PHP θα κατανοήσετε:

- μεταβλητές,
- συναρτήσεις,
- δομές ελέγχου,
- αντικείμενα,
- διαχείριση αρχείων,
- επικοινωνία με βάσεις δεδομένων.

Όλες αυτές οι γνώσεις χρησιμοποιούνται καθημερινά μέσα σε κάθε PHP Framework.

---

# Θα καταλαβαίνετε τι κάνει το Framework

Ένας προγραμματιστής που γνωρίζει μόνο το Framework ξέρει ποια εντολή να χρησιμοποιήσει.

Ένας προγραμματιστής που γνωρίζει και PHP καταλαβαίνει γιατί αυτή η εντολή λειτουργεί.

Αυτό κάνει τεράστια διαφορά όταν χρειαστεί να διορθώσει ένα πρόβλημα ή να υλοποιήσει κάτι που δεν προβλέπεται από το Framework.

---

# Ευκολότερη επίλυση προβλημάτων

Όταν μια εφαρμογή παρουσιάσει κάποιο σφάλμα, πολύ συχνά χρειάζεται να διαβάσουμε τον πραγματικό PHP κώδικα που εκτελείται.

Αν γνωρίζετε μόνο το Framework, η διαδικασία αυτή γίνεται πολύ δυσκολότερη.

---

# Δεν εξαρτάστε από ένα Framework

Τα Frameworks αλλάζουν.

Νέα εμφανίζονται.

Παλιά σταματούν να υποστηρίζονται.

Η γνώση της PHP, όμως, παραμένει χρήσιμη ανεξάρτητα από το Framework που θα χρησιμοποιήσετε στο μέλλον.

Μαθαίνοντας σωστά τη γλώσσα, μπορείτε αργότερα να μεταβείτε πολύ πιο εύκολα από το ένα Framework στο άλλο.

---

# Θα μάθουμε και Frameworks;


Αφού αποκτήσουμε γερές βάσεις στην PHP, θα μπορείτε να μάθετε οποιοδήποτε PHP Framework πολύ πιο εύκολα.

Στόχος αυτής της σειράς δεν είναι να σας μάθει ένα συγκεκριμένο εργαλείο.

Στόχος είναι να σας μάθει να γίνετε καλύτεροι προγραμματιστές.

---

# Ανακεφαλαίωση

Σε αυτό το μάθημα μάθαμε ότι:

- τα Frameworks βασίζονται στην PHP,
- η PHP είναι η θεμελιώδης γνώση,
- η καλή γνώση της γλώσσας διευκολύνει την κατανόηση οποιουδήποτε Framework,
- οι ισχυρές βάσεις είναι πιο σημαντικές από την αποστήθιση εργαλείων.
