# 1.6 - Πώς λειτουργεί το Internet

## Στόχος

Να κατανοήσουμε τι συμβαίνει από τη στιγμή που πληκτρολογούμε μια διεύθυνση στον browser μέχρι να εμφανιστεί η ιστοσελίδα στην οθόνη μας.

---

# Internet και Web

Οι δύο αυτοί όροι χρησιμοποιούνται συχνά σαν να είναι το ίδιο πράγμα.

Δεν είναι.

Το Internet είναι το παγκόσμιο δίκτυο υπολογιστών.

Το Web (World Wide Web) είναι μία από τις υπηρεσίες που λειτουργούν πάνω στο Internet.

Όπως το Email, το FTP και πολλές άλλες υπηρεσίες.

---

# Browser

Ο Browser είναι το πρόγραμμα που χρησιμοποιούμε για να επισκεπτόμαστε ιστοσελίδες.

Παραδείγματα Browsers:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari
- Opera

Ο Browser είναι ο "πελάτης" (Client) που ζητά πληροφορίες από έναν Server.

---

# Server

Ο Server είναι ένας υπολογιστής που είναι συνεχώς συνδεδεμένος στο Internet.

Αποθηκεύει ιστοσελίδες, εφαρμογές, εικόνες και βάσεις δεδομένων και απαντά στα αιτήματα των χρηστών.

Όταν επισκεπτόμαστε μια ιστοσελίδα, στην πραγματικότητα επικοινωνούμε με έναν Server.

---

# Client και Server

Στο Web υπάρχουν πάντα δύο πλευρές.

## Client

Είναι ο υπολογιστής ή το κινητό του επισκέπτη.

Στέλνει αιτήματα.

## Server

Είναι ο υπολογιστής που επεξεργάζεται τα αιτήματα και επιστρέφει την απάντηση.

Αυτό το μοντέλο ονομάζεται Client - Server Architecture.

---

# Τι συμβαίνει όταν επισκεπτόμαστε μια ιστοσελίδα;

Ας υποθέσουμε ότι γράφουμε στον Browser:

```
https://www.example.com
```

Τότε συμβαίνουν τα εξής:

1. Ο Browser ζητά από το DNS να βρει τη διεύθυνση IP που αντιστοιχεί στο `www.example.com`.
2. Το DNS επιστρέφει τη διεύθυνση IP του Server.
3. Ο Browser στέλνει ένα HTTP Request στον Server.
4. Ο Server επεξεργάζεται το αίτημα.
5. Αν χρειάζεται, επικοινωνεί με τη βάση δεδομένων.
6. Δημιουργεί τη σελίδα.
7. Επιστρέφει ένα HTTP Response στον Browser.
8. Ο Browser εμφανίζει την ιστοσελίδα.

Αυτή η διαδικασία ολοκληρώνεται συνήθως μέσα σε λίγα χιλιοστά του δευτερολέπτου.

---

# HTTP Request

Το αίτημα που στέλνει ο Browser προς τον Server ονομάζεται HTTP Request.

Παραδείγματα Requests:

- άνοιγμα μιας σελίδας,
- αποστολή μιας φόρμας,
- σύνδεση ενός χρήστη,
- μεταφόρτωση μιας εικόνας.

---

# HTTP Response

Η απάντηση που επιστρέφει ο Server ονομάζεται HTTP Response.

Η απάντηση μπορεί να περιέχει:

- HTML,
- CSS,
- JavaScript,
- εικόνες,
- αρχεία,
- δεδομένα JSON,
- ή μήνυμα σφάλματος.

---

# Ένα πραγματικό παράδειγμα

Ας υποθέσουμε ότι θέλουμε να συνδεθούμε σε μια εφαρμογή.

Πατάμε το κουμπί **Σύνδεση**.

Ο Browser στέλνει το όνομα χρήστη και τον κωδικό στον Server.

Ο Server:

- ελέγχει τα στοιχεία,
- αναζητά τον χρήστη στη βάση δεδομένων,
- αποφασίζει αν η σύνδεση επιτρέπεται.

Στη συνέχεια επιστρέφει την απάντηση στον Browser.

Ο Browser εμφανίζει είτε το Dashboard είτε ένα μήνυμα λάθους.

---

# Γιατί πρέπει να τα γνωρίζουμε;

Σχεδόν κάθε εφαρμογή που θα δημιουργήσουμε θα λειτουργεί με τον ίδιο τρόπο.

Ο Browser θα στέλνει αιτήματα.

Ο Server θα τα επεξεργάζεται.

Η εφαρμογή θα επιστρέφει αποτελέσματα.

Αυτή είναι η βασική λειτουργία σχεδόν κάθε web εφαρμογής που υπάρχει σήμερα.

---

# Ανακεφαλαίωση

Σε αυτό το μάθημα μάθαμε:

- τι είναι το Internet,
- τι είναι το Web,
- τι είναι ο Browser,
- τι είναι ο Server,
- τι σημαίνει Client,
- τι σημαίνει HTTP Request,
- τι σημαίνει HTTP Response,
- πώς επικοινωνούν μεταξύ τους ο Browser και ο Server.

---

# Στο επόμενο μάθημα

Στο επόμενο μάθημα θα γνωρίσουμε τα Domain Names, το DNS και το Hosting, ώστε να καταλάβουμε πώς ο Browser βρίσκει τον σωστό Server όταν πληκτρολογούμε μια διεύθυνση.
