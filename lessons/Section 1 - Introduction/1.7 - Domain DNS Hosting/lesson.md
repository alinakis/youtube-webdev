# 1.7 - Domain, DNS και Hosting

## Στόχος

Να κατανοήσουμε τι είναι το Domain Name, πώς λειτουργεί το DNS και ποιος είναι ο ρόλος του Hosting στη λειτουργία μιας ιστοσελίδας.

---

# Τι είναι ένα Domain;

Ένα Domain Name είναι η διεύθυνση μιας ιστοσελίδας στο Internet.

Παραδείγματα:

- google.com
- wikipedia.org
- bluehost.gr

Χωρίς τα Domain Names θα έπρεπε να θυμόμαστε αριθμητικές διευθύνσεις IP, κάτι που θα ήταν εξαιρετικά δύσκολο.

---

# Τι είναι μια IP Address;

Κάθε υπολογιστής που είναι συνδεδεμένος στο Internet διαθέτει μία μοναδική διεύθυνση IP.

Για παράδειγμα:

```
192.168.1.1
```

ή

```
185.123.45.67
```

Οι υπολογιστές επικοινωνούν μεταξύ τους χρησιμοποιώντας αυτές τις διευθύνσεις και όχι τα Domain Names.

---

# Τι είναι το DNS;

Το DNS (Domain Name System) λειτουργεί σαν ένας τεράστιος τηλεφωνικός κατάλογος του Internet.

Όταν πληκτρολογούμε:

```
www.bluehost.gr
```

ο Browser δεν γνωρίζει πού βρίσκεται αυτός ο server.

Ρωτά το DNS:

> "Ποια είναι η IP του www.bluehost.gr;"

Το DNS επιστρέφει τη σωστή IP και στη συνέχεια ο Browser επικοινωνεί με τον αντίστοιχο Server.

---

# Τι είναι το Hosting;

Το Hosting είναι ο χώρος στον οποίο φιλοξενείται η ιστοσελίδα ή η web εφαρμογή μας.

Εκεί αποθηκεύονται:

- τα αρχεία της εφαρμογής,
- οι εικόνες,
- τα βίντεο,
- οι βάσεις δεδομένων,
- τα emails,
- και όλες οι υπόλοιπες πληροφορίες.

Ο Hosting Server λειτουργεί συνεχώς, ώστε οι επισκέπτες να μπορούν να έχουν πρόσβαση στην ιστοσελίδα οποιαδήποτε στιγμή.

---

# Πώς συνεργάζονται μεταξύ τους;

Ας δούμε τι συμβαίνει όταν ένας επισκέπτης γράψει:

```
https://www.bluehost.gr
```

1. Ο Browser διαβάζει το Domain Name.
2. Ζητά από το DNS την αντίστοιχη IP.
3. Το DNS επιστρέφει τη διεύθυνση του Server.
4. Ο Browser συνδέεται στον Hosting Server.
5. Ο Server επεξεργάζεται το αίτημα.
6. Επιστρέφει την ιστοσελίδα στον Browser.
7. Ο Browser εμφανίζει το αποτέλεσμα στον χρήστη.

---

# Τα είδη Hosting

Υπάρχουν αρκετοί διαφορετικοί τύποι Hosting.

Οι πιο συνηθισμένοι είναι:

## Shared Hosting

Πολλές ιστοσελίδες φιλοξενούνται στον ίδιο Server.

Είναι η οικονομικότερη λύση και καλύπτει τις ανάγκες των περισσότερων ιστοσελίδων.

---

## VPS (Virtual Private Server)

Ένας φυσικός Server χωρίζεται σε μικρότερους εικονικούς Servers.

Προσφέρει περισσότερους πόρους και μεγαλύτερο έλεγχο.

---

## Dedicated Server

Ολόκληρος ο φυσικός Server ανήκει αποκλειστικά σε έναν πελάτη.

Χρησιμοποιείται σε εφαρμογές με πολύ μεγάλες απαιτήσεις.

---

## Cloud Hosting

Η εφαρμογή λειτουργεί σε πολλούς Servers ταυτόχρονα.

Προσφέρει μεγάλη διαθεσιμότητα και δυνατότητα εύκολης επέκτασης.

---

# Ποιο Hosting θα χρησιμοποιήσουμε;

Για τις ανάγκες αυτής της σειράς, ένα απλό Shared Hosting είναι υπεραρκετό.

Θα μας επιτρέψει να αναπτύξουμε, να δοκιμάσουμε και να δημοσιεύσουμε την εφαρμογή μας σε πραγματικές συνθήκες.

Στο μάθημα **1.10 - Επιλογή Hosting** θα αναλύσουμε αναλυτικά όλα τα χαρακτηριστικά που πρέπει να προσέχουμε πριν επιλέξουμε έναν πάροχο φιλοξενίας.
