# 1.8 - Frontend και Backend

## Στόχος

Να κατανοήσουμε τη διαφορά μεταξύ Frontend και Backend, καθώς και τον τρόπο με τον οποίο συνεργάζονται για τη δημιουργία μιας σύγχρονης web εφαρμογής.

---

# Τι είναι το Frontend;

Frontend ονομάζεται ό,τι βλέπει και χρησιμοποιεί ο επισκέπτης μιας ιστοσελίδας.

Για παράδειγμα:

- το μενού,
- τα κουμπιά,
- οι εικόνες,
- τα κείμενα,
- οι φόρμες,
- οι πίνακες,
- τα χρώματα και η μορφοποίηση.

Με λίγα λόγια, το Frontend είναι το γραφικό περιβάλλον της εφαρμογής.

---

# Οι βασικές τεχνολογίες του Frontend

Το Frontend βασίζεται κυρίως στις εξής τεχνολογίες:

## HTML

Περιγράφει τη δομή της ιστοσελίδας.

## CSS

Καθορίζει την εμφάνιση της ιστοσελίδας.

## JavaScript

Προσθέτει αλληλεπίδραση και δυναμική συμπεριφορά.

---

# Τι είναι το Backend;

Backend ονομάζεται ο κώδικας που εκτελείται στον Server και δεν είναι ορατός στον επισκέπτη.

Το Backend αναλαμβάνει εργασίες όπως:

- σύνδεση χρηστών,
- αποθήκευση δεδομένων,
- επεξεργασία φορμών,
- επικοινωνία με τη βάση δεδομένων,
- έλεγχο δικαιωμάτων,
- αποστολή email.

---

# Οι βασικές τεχνολογίες του Backend

Στη σειρά αυτή θα χρησιμοποιήσουμε:

## PHP

Επεξεργάζεται τα αιτήματα των χρηστών και δημιουργεί τις δυναμικές σελίδες.

## MySQL

Αποθηκεύει τα δεδομένα της εφαρμογής.

---

# Πώς συνεργάζονται;

Ας υποθέσουμε ότι ένας χρήστης συμπληρώνει μια φόρμα σύνδεσης.

Το Frontend εμφανίζει:

- τα πεδία Username και Password,
- το κουμπί «Σύνδεση».

Όταν ο χρήστης πατήσει το κουμπί:

1. Το Frontend στέλνει τα στοιχεία στον Server.
2. Η PHP επεξεργάζεται το αίτημα.
3. Η PHP ελέγχει τα στοιχεία στη βάση δεδομένων.
4. Δημιουργείται η κατάλληλη απάντηση.
5. Το αποτέλεσμα επιστρέφει στον Browser.
6. Το Frontend εμφανίζει είτε το Dashboard είτε μήνυμα λάθους.

---

# Γιατί πρέπει να γνωρίζουμε και τα δύο;

Μια σύγχρονη web εφαρμογή δεν αποτελείται μόνο από όμορφες σελίδες.

Ούτε μόνο από σωστό προγραμματισμό στον Server.

Χρειάζεται σωστή συνεργασία μεταξύ Frontend και Backend, ώστε η εφαρμογή να είναι:

- λειτουργική,
- ασφαλής,
- γρήγορη,
- εύχρηστη.

---

# Full Stack Developer

Ένας Full Stack Developer μπορεί να αναπτύσσει τόσο το Frontend όσο και το Backend μιας εφαρμογής.

Δεν σημαίνει απαραίτητα ότι γνωρίζει τα πάντα.

Σημαίνει όμως ότι μπορεί να κατανοήσει και να εργαστεί και στα δύο μέρη μιας εφαρμογής.

---

# Τι θα μάθουμε σε αυτή τη σειρά;

Σε αυτή τη σειρά θα δημιουργήσουμε μια ολοκληρωμένη Full Stack Web Application.

Θα ξεκινήσουμε από το Frontend, θα περάσουμε στο Backend και στη συνέχεια θα συνδέσουμε τα δύο μεταξύ τους, μέχρι να δημιουργήσουμε μια πλήρως λειτουργική εφαρμογή.

---

# Ανακεφαλαίωση

Σε αυτό το μάθημα μάθαμε:

- τι είναι το Frontend,
- ποιες τεχνολογίες χρησιμοποιεί,
- τι είναι το Backend,
- ποιες τεχνολογίες χρησιμοποιεί,
- πώς συνεργάζονται μεταξύ τους,
- τι σημαίνει Full Stack Developer.

---

# Στο επόμενο μάθημα

Στο επόμενο μάθημα θα δούμε τη διαφορά ανάμεσα στις στατικές και τις δυναμικές ιστοσελίδες και θα καταλάβουμε γιατί οι περισσότερες σύγχρονες εφαρμογές είναι δυναμικές.
