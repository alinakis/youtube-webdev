# 1.9 - Στατικές και Δυναμικές Ιστοσελίδες

## Στόχος

Να κατανοήσουμε τη διαφορά μεταξύ στατικών και δυναμικών ιστοσελίδων και να δούμε γιατί οι περισσότερες σύγχρονες εφαρμογές είναι δυναμικές.

---

# Τι είναι μια στατική ιστοσελίδα;

Μια στατική ιστοσελίδα εμφανίζει ακριβώς το ίδιο περιεχόμενο σε κάθε επισκέπτη.

Ο Server απλώς στέλνει το αρχείο HTML στον Browser, χωρίς να εκτελεί κάποιον προγραμματιστικό κώδικα.

Παραδείγματα:

- προσωπική ιστοσελίδα,
- εταιρική παρουσίαση,
- portfolio,
- landing page.

---

# Πλεονεκτήματα των στατικών ιστοσελίδων

- Πολύ γρήγορες.
- Απλές στην κατασκευή.
- Αυξημένη ασφάλεια.
- Μικρές απαιτήσεις σε πόρους.

---

# Μειονεκτήματα των στατικών ιστοσελίδων

Κάθε αλλαγή πρέπει να γίνεται χειροκίνητα.

Αν έχουμε 100 σελίδες και θέλουμε να αλλάξουμε το μενού, πιθανόν να χρειαστεί να τροποποιήσουμε και τις 100.

Επίσης:

- δεν υπάρχει σύνδεση χρηστών,
- δεν υπάρχει βάση δεδομένων,
- δεν υπάρχει εξατομίκευση περιεχομένου.

---

# Τι είναι μια δυναμική ιστοσελίδα;

Μια δυναμική ιστοσελίδα δημιουργείται τη στιγμή που τη ζητά ο επισκέπτης.

Ο Server εκτελεί κώδικα, ανακτά δεδομένα από τη βάση δεδομένων και δημιουργεί το τελικό αποτέλεσμα πριν το στείλει στον Browser.

Έτσι, δύο διαφορετικοί χρήστες μπορεί να βλέπουν διαφορετικό περιεχόμενο, παρότι επισκέπτονται την ίδια διεύθυνση.

---

# Παραδείγματα δυναμικών εφαρμογών

- Facebook
- YouTube
- Gmail
- ηλεκτρονικά καταστήματα
- τραπεζικές εφαρμογές
- συστήματα κρατήσεων
- πληροφοριακά συστήματα επιχειρήσεων

---

# Πλεονεκτήματα των δυναμικών ιστοσελίδων

- Περιεχόμενο που ενημερώνεται αυτόματα.
- Σύνδεση χρηστών.
- Διαχείριση δεδομένων μέσω βάσεων δεδομένων.
- Εξατομίκευση για κάθε χρήστη.
- Εύκολη συντήρηση και επέκταση.

---

# Μειονεκτήματα των δυναμικών ιστοσελίδων

- Μεγαλύτερη πολυπλοκότητα.
- Απαιτούν Backend προγραμματισμό.
- Χρειάζονται βάση δεδομένων.
- Απαιτούν περισσότερη προσοχή στην ασφάλεια.

---

# Ένα απλό παράδειγμα

Ας υποθέσουμε ότι δημιουργούμε μια ιστοσελίδα με νέα.

## Στατική ιστοσελίδα

Για κάθε νέο άρθρο δημιουργούμε χειροκίνητα ένα νέο αρχείο HTML.

## Δυναμική ιστοσελίδα

Τα άρθρα αποθηκεύονται στη βάση δεδομένων.

Όταν ο επισκέπτης ανοίξει τη σελίδα, η εφαρμογή ανακτά τα άρθρα και τα εμφανίζει αυτόματα.

Δεν χρειάζεται να δημιουργούμε νέα HTML σελίδα κάθε φορά.

---

# Τι θα δημιουργήσουμε εμείς;

Στο τέλος αυτής της σειράς δεν θα έχουμε μια απλή ιστοσελίδα.

Θα δημιουργήσουμε μια πραγματική δυναμική web εφαρμογή, η οποία:

- θα χρησιμοποιεί PHP,
- θα αποθηκεύει δεδομένα στη MySQL,
- θα διαθέτει σύστημα σύνδεσης χρηστών,
- θα διαχειρίζεται πληροφορίες μέσω βάσης δεδομένων,
- θα δημιουργεί δυναμικά το περιεχόμενο που εμφανίζεται στον Browser.

---

# Ανακεφαλαίωση

Σε αυτό το μάθημα μάθαμε:

- τι είναι μια στατική ιστοσελίδα,
- ποια είναι τα πλεονεκτήματα και τα μειονεκτήματά της,
- τι είναι μια δυναμική ιστοσελίδα,
- γιατί οι περισσότερες σύγχρονες εφαρμογές είναι δυναμικές.

---
